# Oracle SQL & PL/SQL — Skills

Senior Oracle SQL / PL/SQL engineering skills (14+ years), packaged as a
Claude Code skill in
[`.claude/skills/oracle-sql-plsql-expert`](.claude/skills/oracle-sql-plsql-expert/SKILL.md).
Each area links to a reference guide with patterns, examples, and pitfalls.

## Core Strengths

- Oracle performance tuning: execution plan and optimizer analysis
- High-volume data processing with BULK COLLECT and FORALL
- Advanced analytical SQL
- Complex PL/SQL architecture
- Production troubleshooting and SQL performance diagnosis
- Database design, plus partitioning and indexing strategy
- Concurrency and transaction management
- Technical leadership and code review
